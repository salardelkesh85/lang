## ۱. معرفی و فلسفهٔ طراحی

**Nova** یک زبان برنامه‌نویسی **با تایپ ایستا**، **امری** و دارای **بخش اعلانی برای رابط کاربری** است که برای ساخت اپلیکیشن‌های اندروید طراحی شده است. کامپایلر Nova برنامه را به **Kotlin + Jetpack Compose** (فناوری رسمی گوگل برای رابط کاربری اندروید) ترجمه می‌کند و یک پروژهٔ کامل Android Studio می‌سازد.

| اصل طراحی | چگونه رعایت شده |
|---|---|
| **خوانایی (Readability)** | کلمات کلیدی انگلیسی کوتاه (`and`, `or`, `not`)، بدون `;` و بدون پرانتز دور شرط |
| **قابلیت نوشتن (Writability)** | ساختارهای `app`/`screen`/`state` جزو خود زبان‌اند؛ یک اپ کامل در ۱۰ خط |
| **قابلیت اطمینان (Reliability)** | تایپ ایستا، لیست‌های تغییرناپذیر، و بررسی‌های زمان کامپایل (مثلاً `return` در همهٔ مسیرها) |
| **تعامد (Orthogonality)** | هر عبارت در هر جایی که مقدار لازم است قابل استفاده است: در درون‌یابی رشته، آرگومان UI و شرط |
| **هزینهٔ کم** | خروجی، کد Kotlin بومی است و سرباری در زمان اجرا ندارد |

### دسته‌بندی زبان
- **پارادایم:** امری (Imperative) و رویه‌ای (Procedural)، به‌علاوهٔ زیرزبان اعلانی (Declarative DSL) برای UI
- **سیستم نوع:** ایستا (Static)، قوی (Strong)، با استنتاج نوع محلی (Local Type Inference)
- **حوزه:** ایستا/واژگانی (Lexical Scope) با بلوک‌های تودرتو
- **مدیریت حافظه:** خودکار (Garbage Collection توسط JVM/ART)
- **روش پیاده‌سازی:** ترجمهٔ منبع‌به‌منبع (Transpiler) به Kotlin و مفسر درخت‌پیما برای اجرای فوری

## ۲. ساختار واژگانی

### ۲.۱ توضیحات
```nova
// توضیح تک‌خطی
/* توضیح
   چندخطی */
```

### ۲.۲ شناسه‌ها
شناسه با یک حرف یا `_` شروع می‌شود و می‌تواند حرف و رقم داشته باشد. **حروف فارسی مجازند:**
```nova
let قیمت = 25000
let total_price = قیمت * 2
```
شناسه‌هایی که با `nv_` شروع شوند برای کتابخانهٔ زمان اجرا رزرو شده‌اند.

### ۲.۳ کلمات کلیدی
```
let  var  fun  return  if  else  while  for  in  break  continue
true  false  and  or  not  app  screen  state
```
نام انواع (`Int`، `Float`، `List` و ...) و نام عناصر UI (`text`، `button` و ...) کلمهٔ کلیدی نیستند؛ فقط در جای خودشان معنای ویژه دارند.

### ۲.۴ لیترال‌ها
| نوع | مثال |
|---|---|
| صحیح | `42`  `۱۴۰۳`  `1_000_000` |
| اعشاری | `3.14`  `2.5e-3`  `1e6` |
| منطقی | `true`  `false` |
| رشته | `"سلام"`  `"خط\nجدید"`  `"مجموع: {a + b}"` |
| لیست | `[1, 2, 3]`  `["الف", "ب"]`  `[]` |

**درون‌یابی رشته (String Interpolation):** هر عبارتی داخل `{ }` در رشته محاسبه و به متن تبدیل می‌شود. برای خود کاراکتر آکولاد از `\{` و `\}` استفاده کنید.

**دنباله‌های گریز:** `\n` `\t` `\"` `\\` `\{` `\}`

### ۲.۵ پایان دستور
دستورها با **خط جدید** یا `;` تمام می‌شوند. عبارت‌ها می‌توانند بعد از یک عملگر در خط بعد ادامه پیدا کنند:
```nova
let total = price +
            tax
```
اما `(` یا `[` در ابتدای خط جدید، شروع دستور جدید است، نه فراخوانی یا اندیس.

## ۳. انواع داده

| نوع | توضیح | معادل Kotlin |
|---|---|---|
| `Int` | عدد صحیح علامت‌دار **۳۲ بیتی** (−2147483648 تا 2147483647) | `Int` |
| `Float` | عدد اعشاری ۶۴ بیتی (IEEE 754) | `Double` |
| `Bool` | `true` / `false` | `Boolean` |
| `String` | رشتهٔ یونیکد، تغییرناپذیر | `String` |
| `List<T>` | لیست **تغییرناپذیر** از عناصر نوع T | `List<T>` |
| `Void` | «بدون مقدار»؛ فقط نوع بازگشتی تابع | `Unit` |

در Nova هیچ متغیری بدون مقدار اولیه تعریف نمی‌شود، پس `null` وجود ندارد.

### ۳.۱ استنتاج نوع
```nova
let a = 5            // Int
let b = 2.5          // Float
let c = [1, 2.5]     // List<Float>  (Int به Float ارتقا می‌یابد)
let d: List<String> = []   // لیست خالی نیاز به نوع صریح دارد
```

### ۳.۲ تبدیل نوع
- **ضمنی:** فقط `Int → Float` (ارتقای عددی، بدون از دست رفتن دقت). در خروجی Kotlin به `.toDouble()` تبدیل می‌شود.
- **صریح:** با توابع `int()`، `float()`، `str()`.

```nova
let x: Float = 3        // مجاز: 3.0
let y: Int = 2.7        // خطا: expected Int, got Float
let z: Int = int(2.7)   // 2  (برش به سمت صفر)
```

### ۳.۳ چرا لیست‌ها تغییرناپذیرند؟
در Jetpack Compose، صفحه وقتی دوباره رسم می‌شود که **مقدار** یک state عوض شود. اگر لیست درجا تغییر کند (`list.add(x)`)، مرجع آن عوض نمی‌شود و Compose متوجه تغییر نمی‌شود. این یک باگ رایج در اندروید است. در Nova هر تغییر یک لیست جدید می‌سازد:
```nova
tasks = tasks + [newTask]      // لیست جدید، پس صفحه به‌روز می‌شود
tasks = remove(tasks, 0)
```
یعنی **یک دستهٔ کامل از باگ‌ها در سطح طراحی زبان حذف شده است.**

## ۴. متغیرها و ثابت‌ها

```nova
let pi = 3.14159        // ثابت: مقداردهی دوباره ممنوع است
var count = 0           // متغیر
var name: String = ""   // با نوع صریح

count = count + 1
count += 1              // معادل خط بالا؛ همچنین -= و *= و /=
```

| کلمه | قابل تغییر؟ | معادل Kotlin |
|---|---|---|
| `let` | خیر | `val` |
| `var` | بله | `var` |
| `state` | بله، فقط داخل رویداد دکمه؛ تغییرش صفحه را دوباره رسم می‌کند | `var x by rememberSaveable { mutableStateOf(...) }` |

## ۵. عملگرها

### ۵.۱ جدول اولویت (از کم به زیاد)
| سطح | عملگر | شرکت‌پذیری | نوع عملوند |
|---|---|---|---|
| 1 | `or` | چپ | Bool |
| 2 | `and` | چپ | Bool |
| 3 | `not` | یکانی، پیشوندی | Bool |
| 4 | `==` `!=` `<` `<=` `>` `>=` | **غیرشرکت‌پذیر** | اعداد، رشته‌ها (برای `==` هر نوع هم‌جنس) |
| 5 | `+` `-` | چپ | اعداد؛ `+` برای رشته و لیست هم کار می‌کند |
| 6 | `*` `/` `%` | چپ | اعداد |
| 7 | `-` (منفی) | یکانی، پیشوندی | اعداد |
| 8 | `f(...)`  `a[i]` | چپ | |

### ۵.۲ معنای عملگرها
- `Int / Int` تقسیم صحیح است و به سمت صفر گرد می‌شود: `7 / 2 == 3` و `-7 / 2 == -3`
- `%` باقیمانده با علامت مقسوم: `-7 % 3 == -1`
- اگر یکی از عملوندها `Float` باشد، نتیجه `Float` است: `7 / 2.0 == 3.5`
- `+` با یک رشته، الحاق رشته‌ای است: `"a" + 1 + 2 == "a12"` ولی `1 + 2 + "a" == "3a"`
- `+` روی دو لیست، الحاق آن‌هاست: `[1, 2] + [3] == [1, 2, 3]`
- `and` و `or` **اتصال کوتاه (short-circuit)** دارند.
- `==` مقایسهٔ **ساختاری** است: `[1, 2] == [1, 2]` درست است.

## ۶. دستورهای کنترلی

### ۶.۱ شرط
```nova
if score >= 90 {
    grade = "A"
} else if score >= 75 {
    grade = "B"
} else {
    grade = "C"
}
```
شرط باید از نوع `Bool` باشد (`if 1 { }` خطای نوع است). آکولاد اجباری است.

### ۶.۲ حلقهٔ while
```nova
while n > 1 {
    n /= 2
}
```

### ۶.۳ حلقهٔ for
```nova
for i in 0..5 { }        // 0, 1, 2, 3, 4     (انتهای باز)
for i in 1..=5 { }       // 1, 2, 3, 4, 5     (انتهای بسته)
for name in names { }    // پیمایش لیست
for ch in "سلام" { }     // پیمایش کاراکترهای رشته (هر کاراکتر یک String)
```
متغیر حلقه **ثابت** است و در هر تکرار مقدار جدید می‌گیرد. مرزهای بازه فقط یک بار، قبل از شروع حلقه محاسبه می‌شوند.

### ۶.۴ break و continue
`break` از درونی‌ترین حلقه خارج می‌شود و `continue` به تکرار بعد می‌رود. استفاده از آن‌ها بیرون از حلقه خطای کامپایل است.

## ۷. توابع

```nova
fun area(w: Float, h: Float): Float {
    return w * h
}

fun greet(name: String) {          // بدون نوع بازگشتی، یعنی Void
    print("سلام {name}")
}
```
- نوع همهٔ پارامترها باید صریح باشد.
- پارامترها ثابت‌اند (قابل مقداردهی دوباره نیستند).
- **ارسال با مقدار (Pass by Value):** چون همهٔ انواع تغییرناپذیرند، تابع نمی‌تواند آرگومان را تغییر دهد.
- توابع **بازگشتی** و **ارجاع پیش‌رو** مجازند (می‌توان تابعی را صدا زد که پایین‌تر تعریف شده).
- تابعی که نوع بازگشتی دارد باید در **همهٔ مسیرهای اجرا** `return` داشته باشد. کامپایلر این را با تحلیل جریان کنترل بررسی می‌کند.
- سربارگذاری (Overloading) پشتیبانی نمی‌شود و نام هر تابع یکتاست.
- `fun main()` نقطهٔ شروع برنامه‌های متنی است (دستور `run`).

## ۸. توابع داخلی (Built-in)

| تابع | امضا | توضیح |
|---|---|---|
| `print(x)` | `Any → Void` | چاپ در خروجی (در اندروید: Logcat) |
| `str(x)` | `Any → String` | تبدیل به رشته |
| `int(x)` | `Int/Float/String → Int` | Float: برش به سمت صفر. String نامعتبر: `0` |
| `float(x)` | `Int/Float/String → Float` | String نامعتبر: `0.0` |
| `len(x)` | `String/List<T> → Int` | طول |
| `contains(a, b)` | `(List<T>, T) → Bool` یا `(String, String) → Bool` | عضویت |
| `remove(xs, i)` | `(List<T>, Int) → List<T>` | لیست جدید بدون عنصر i |
| `random(a, b)` | `(Int, Int) → Int` | عدد تصادفی در بازهٔ بستهٔ [a, b] |
| `sqrt(x)` | `Float → Float` | جذر |
| `abs(x)` | `Int → Int` یا `Float → Float` | قدر مطلق |
| `format(x, d)` | `(Float, Int) → String` | نمایش با d رقم اعشار: `format(3.14159, 2) == "3.14"` |
| `toast(x)` | `Any → Void` | پیام کوتاه اندروید (**فقط داخل رویداد دکمه**) |
| `navigate(S)` | `Screen → Void` | رفتن به صفحهٔ S (**فقط داخل رویداد دکمه**) |
| `back()` | `→ Void` | بازگشت به صفحهٔ قبل (**فقط داخل رویداد دکمه**) |

## ۹. اپلیکیشن، صفحه و state

```nova
app "عنوان اپ" {             // عنوانی که زیر آیکون اپ نمایش داده می‌شود
    screen Main {            // اولین صفحه = صفحهٔ شروع
        state n: Int = 0     // stateها باید اول صفحه بیایند
        ...عناصر UI...
    }
    screen Settings { ... }
}
```

### مدل اجرایی (همان مدل Compose)
1. وقتی صفحه نمایش داده می‌شود، stateها یک بار مقدار اولیه می‌گیرند.
2. بدنهٔ صفحه، یک **توصیف** از رابط کاربری است، نه دنباله‌ای از دستورها. هر بار که یک state تغییر کند، کل توصیف دوباره ارزیابی و صفحه به‌روز می‌شود (**Recomposition**).
3. state فقط داخل **رویداد** (بلوک دکمه) قابل تغییر است. این جلوی حلقهٔ بی‌نهایتِ «تغییر state، رسم دوباره، تغییر state» را می‌گیرد.
4. `navigate(S)` صفحهٔ S را روی **پشته** می‌گذارد و `back()` (یا دکمهٔ Back گوشی) آن را برمی‌دارد. state صفحه‌های داخل پشته حفظ می‌شود (حتی با چرخش گوشی).

## ۱۰. عناصر رابط کاربری

| عنصر | آرگومان‌ها | ترجمه به Compose |
|---|---|---|
| `column { ... }` | | `Column` (چیدمان عمودی) |
| `row { ... }` | | `Row` (چیدمان افقی) |
| `text(x)` / `text(x, size)` | هر نوع، اندازهٔ فونت Int | `Text` |
| `title(x)` | هر نوع | `Text` با سبک تیتر |
| `button(label) { ... }` | برچسب + بلوک رویداد | `Button(onClick = { ... })` |
| `input(s)` / `input(s, hint)` | state از نوع String | `OutlinedTextField` (اتصال دوطرفه) |
| `checkbox(b)` / `checkbox(b, label)` | state از نوع Bool | `Checkbox` |
| `spacer()` / `spacer(n)` | فاصله بر حسب dp | `Spacer` |
| `divider()` | | `HorizontalDivider` |

ساختارهای کنترلی هم داخل UI کار می‌کنند:
```nova
if len(items) == 0 {
    text("لیست خالی است")
} else {
    for i in 0..len(items) {
        row {
            text(items[i])
            button("حذف") { items = remove(items, i) }
        }
    }
}
```

## ۱۱. قواعد حوزه (Scope)

Nova **حوزهٔ ایستا** دارد. حوزه‌ها از بیرون به درون:
1. **سراسری:** متغیرهای `let`/`var` سطح بالا و همهٔ توابع
2. **تابع:** پارامترها
3. **صفحه:** stateهای آن صفحه
4. **بلوک:** هر `{ }` (بدنهٔ if، حلقه، رویداد دکمه) یک حوزهٔ جدید است

- تعریف دوبارهٔ یک نام در **همان** حوزه خطاست.
- تعریف همان نام در حوزهٔ درونی‌تر مجاز است و نام بیرونی را **پنهان (shadow)** می‌کند.
- متغیر قبل از تعریف قابل استفاده نیست. توابع استثنا هستند، چون امضای همهٔ توابع در گذر اول جمع‌آوری می‌شود.
- توابع به stateهای صفحه دسترسی ندارند؛ باید مقدار را به‌صورت پارامتر بگیرند. این باعث می‌شود منطق برنامه از رابط کاربری جدا بماند.

## ۱۲. قواعد معنایی و خطاها

کامپایلر سه دسته خطا تولید می‌کند و هر کدام **موقعیت دقیق** (سطر:ستون) و خط کد را نشان می‌دهد:

```
app.nova:5:17: type error: type mismatch for variable 'count': expected Int, got String
            count = "ده"
                    ^
```

| دسته | مثال‌ها |
|---|---|
| **واژگانی** | رشتهٔ بسته‌نشده، کاراکتر غیرمجاز، عدد خیلی بزرگ |
| **نحوی** | `)` جاافتاده، مقایسهٔ زنجیره‌ای، عنصر UI ناشناخته، state بعد از UI |
| **معنایی** | نوع ناسازگار، متغیر تعریف‌نشده، تعریف تکراری، تغییر `let`، تعداد آرگومان اشتباه، نبودن `return`، `break` بیرون حلقه، `toast` بیرون رویداد، `navigate` به صفحهٔ ناموجود، استفاده از مقدار تابع Void |
| **زمان اجرا** | تقسیم صحیح بر صفر، اندیس خارج از محدوده، `random` با بازهٔ خالی، بازگشت بی‌پایان |

## ۱۳. معناشناسی زمان اجرا

برای اینکه برنامه روی گوشی (Kotlin) و در شبیه‌ساز (مفسر پایتون) **دقیقاً یکسان** رفتار کند، این موارد تعریف شده‌اند:

| موضوع | رفتار |
|---|---|
| سرریز Int | گردش ۳۲ بیتی: `2147483647 + 1 == -2147483648` |
| تقسیم Float بر صفر | `Infinity` یا `NaN` (خطا نمی‌دهد) |
| تقسیم Int بر صفر | خطای زمان اجرا |
| چاپ Float | قالب Kotlin: `1.0E7`، `0.001`، `1.0E-4`، `100.0` |
| چاپ Bool | `true` / `false` |
| چاپ لیست | `[1, 2, 3]` |
| ترتیب ارزیابی | آرگومان‌ها و عملوندها از چپ به راست |
| اندیس رشته | یک رشتهٔ یک‌کاراکتری برمی‌گرداند |
