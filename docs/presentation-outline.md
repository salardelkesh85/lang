# مطالب ارائه (پاورپوینت): زبان برنامه‌نویسی **Nova** برای اندروید

> هر بخش = یک اسلاید. «متن اسلاید» همان چیزی است که روی اسلاید می‌نویسید و «گفتار» چیزی است که هنگام ارائه می‌گویید.

---

## اسلاید ۱: عنوان
**متن اسلاید:**
- Nova: یک زبان برنامه‌نویسی برای ساخت اپلیکیشن اندروید
- درس طراحی زبان‌های برنامه‌نویسی
- نام ارائه‌دهنده / نام استاد / تاریخ

**گفتار:** Nova در لاتین یعنی «ستارهٔ نو»: ستاره‌ای که ناگهان درخشان می‌شود. هدف ما زبانی است که ساخت اپ اندروید را ساده و کوتاه کند.

---

## اسلاید ۲: مسئله
**متن اسلاید:**
- برای یک اپ سادهٔ «شمارنده» در اندروید باید با Kotlin، Gradle، Activity، Compose و State کار کرد
- ده‌ها خط کد تکراری (boilerplate)
- منحنی یادگیری سخت برای مبتدی‌ها

**گفتار:** یک اپ با یک دکمه و یک عدد، در Kotlin حدود ۴۰ تا ۵۰ خط کد و چند فایل پیکربندی لازم دارد.

---

## اسلاید ۳: هدف‌های طراحی
**متن اسلاید:**
1. **سادگی:** نحو کوتاه و خوانا
2. **ایمنی:** تایپ ایستا؛ خطاها قبل از اجرا گرفته می‌شوند
3. **مخصوص اندروید:** صفحه، وضعیت (state) و رابط کاربری جزو خودِ زبان‌اند
4. **سازگاری:** خروجی، کد Kotlin + Jetpack Compose است، یعنی همان فناوری رسمی گوگل
5. **فارسی‌دوست:** شناسه‌ها و ارقام فارسی مجازند

---

## اسلاید ۴: Nova در یک نگاه (مثال)
```nova
app "شمارنده" {
  screen Main {
    state count: Int = 0

    title("شمارنده")
    text("مقدار: {count}")
    button("افزایش") { count += 1 }
    button("صفر کن") { count = 0 }
  }
}
```
**گفتار:** همین ۱۰ خط به یک پروژهٔ کامل اندروید با Jetpack Compose ترجمه می‌شود.

---

## اسلاید ۵: دسته‌بندی زبان (Paradigm)
**متن اسلاید:**
- **امری (Imperative)** + **اعلانی (Declarative)** برای رابط کاربری
- **تایپ ایستا** با **استنتاج نوع** (`let x = 5` یعنی x از نوع Int است)
- **تایپ قوی:** تبدیل ضمنی فقط Int → Float
- **حوزهٔ ایستا (Lexical Scope)**
- پیاده‌سازی: **مترجم منبع‌به‌منبع (Transpiler)** به Kotlin + **مفسر (Interpreter)** برای تست

---

## اسلاید ۶: انواع داده (Type System)
| نوع Nova | معادل Kotlin | مثال |
|---|---|---|
| `Int` (۳۲ بیتی) | `Int` | `42`, `۱۴۰۳` |
| `Float` | `Double` | `3.14` |
| `Bool` | `Boolean` | `true` |
| `String` | `String` | `"سلام {name}"` |
| `List<T>` | `List<T>` | `[1, 2, 3]` |
| `Void` | `Unit` | (تابع بدون خروجی) |

**گفتار:** لیست‌ها تغییرناپذیرند (immutable)، یعنی با هر تغییر یک لیست جدید ساخته می‌شود. این با مدل Compose که با تغییر state صفحه را دوباره می‌سازد کاملاً جور است.

## اسلاید ۷: نحو پایه
```nova
let pi = 3.14            // ثابت (تغییرناپذیر)
var total: Int = 0       // متغیر

fun fact(n: Int): Int {
  if n <= 1 { return 1 }
  return n * fact(n - 1)
}

for i in 0..10 { total += i }      // 0 تا 9
for i in 1..=5 { print(i) }        // 1 تا 5
while total > 0 { total -= 7 }
```
- بدون `;` اجباری (پایان دستور با خط جدید)
- شرط‌ها بدون پرانتز ولی بدنه حتماً با `{ }`، پس ابهام «dangling else» پیش نمی‌آید

---

## اسلاید ۸: ساختارهای ویژهٔ اندروید
| ساختار | معنا | ترجمه در Compose |
|---|---|---|
| `app "عنوان" { }` | کل اپلیکیشن | `MainActivity` |
| `screen Name { }` | یک صفحه | تابع `@Composable` |
| `state x = 0` | وضعیت واکنش‌گرا | `remember { mutableStateOf(0) }` |
| `column { }` / `row { }` | چیدمان | `Column` / `Row` |
| `text()`, `title()` | متن | `Text` |
| `button("..") { }` | دکمه + رویداد | `Button(onClick = {..})` |
| `input(name, "راهنما")` | ورودی متن | `OutlinedTextField` |
| `checkbox(done, "..")` | چک‌باکس | `Checkbox` |
| `navigate(Other)`, `back()` | جابه‌جایی بین صفحه‌ها | پشتهٔ صفحات |
| `toast("..")` | پیام کوتاه | `Toast.makeText` |

## اسلاید ۹: گرامر (نمونهٔ EBNF)
```ebnf
program    = { funDecl | varDecl | appDecl } ;
appDecl    = "app" STRING "{" { screenDecl } "}" ;
screenDecl = "screen" IDENT "{" { stateDecl } { uiNode } "}" ;
funDecl    = "fun" IDENT "(" [ params ] ")" [ ":" type ] block ;
stmt       = varDecl | assign | ifStmt | whileStmt | forStmt
           | "return" [ expr ] | "break" | "continue" | expr ;
expr       = orExpr ;
orExpr     = andExpr { "or" andExpr } ;
andExpr    = notExpr { "and" notExpr } ;
...
```
**گفتار:** گرامر طوری طراحی شده که با یک پارسر «نزولی بازگشتی» (Recursive Descent) و فقط با یک توکن پیش‌نگری، یعنی LL(1)، قابل تجزیه باشد.

## اسلاید ۱۱: معماری کامپایلر
```
کد .nova
  │
  ▼
[۱] تحلیل واژگانی (Lexer)      → توکن‌ها
  ▼
[۲] تحلیل نحوی (Parser)        → درخت نحو انتزاعی (AST)
  ▼
[۳] تحلیل معنایی (Type Checker) → AST نوع‌دار + جدول نمادها
  ▼
  ├──► [۴الف] مفسر / شبیه‌ساز   → اجرای فوری در ترمینال
  └──► [۴ب] تولید کد Kotlin    → پروژهٔ کامل Android Studio
```

## اسلاید ۱۲: فاز ۱: تحلیل واژگانی
- ورودی: `count += 1`
- خروجی: `IDENT(count)  PLUS_ASSIGN  INT(1)`
- نکات: پشتیبانی از ارقام فارسی (`۱۲` → 12)، شناسهٔ فارسی، درون‌یابی رشته `"{x}"`، توضیحات `//` و `/* */`
- دستور نمایش: `python -m nova tokens file.nova`

---

## اسلاید ۱۳: فاز ۲: تحلیل نحوی و AST
- `1 + 2 * 3` →
```
Binary(+)
├── Int(1)
└── Binary(*)
    ├── Int(2)
    └── Int(3)
```
- دستور نمایش: `python -m nova ast file.nova`

## اسلاید ۱۴: فاز ۳: تحلیل معنایی
خطاهایی که **قبل از اجرا** گرفته می‌شوند:
- متغیر تعریف‌نشده / تعریف تکراری
- مقداردهی دوباره به ثابت `let`
- ناسازگاری نوع: `let x: Int = "hi"`
- تعداد یا نوع آرگومان اشتباه در فراخوانی تابع
- تابعی که در همهٔ مسیرها `return` ندارد
- `break` بیرون از حلقه
- `toast`/`navigate` بیرون از رویداد دکمه
- `navigate` به صفحه‌ای که وجود ندارد

```
counter.nova:5:9: type error: cannot assign String to variable 'count' of type Int
        count = "ده"
        ^
```

## اسلاید ۱۵: فاز ۴: تولید کد
**Nova:**
```nova
state count: Int = 0
button("افزایش") { count += 1 }
```
**Kotlin تولیدشده:**
```kotlin
var count by rememberSaveable { mutableStateOf<Int>(0) }
Button(onClick = {
    count += 1
}) { Text(text = "افزایش") }
```
خروجی: پروژهٔ کامل Gradle (`MainActivity.kt`، `AndroidManifest.xml`، `build.gradle.kts`) که مستقیم در Android Studio باز و روی گوشی اجرا می‌شود.

## اسلاید ۱۶: شبیه‌ساز و اجرای مستقیم
