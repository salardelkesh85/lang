# ارائهٔ Nova

| فایل | توضیح |
|---|---|
| `Nova.pptx` | فایل اصلی پاورپوینت (۱۹ اسلاید، انیمیشن و ترنزیشن Morph) |
| `Nova.pdf` | نسخهٔ پشتیبان PDF (بدون انیمیشن؛ برای وقتی که سیستم ارائه فونت‌ها را ندارد) |
| `fonts/` | فونت‌های استفاده‌شده (همه رایگان با مجوز OFL) |
| `source/` | اسکریپت‌های ساخت ارائه و آیکون‌ها |

## ⚠️ قبل از ارائه حتماً فونت‌ها را نصب کنید
روی هر دو فایل زیر کلیک راست کنید و **Install for all users** را بزنید، **سپس PowerPoint را ببندید و دوباره باز کنید**:

- `Vazirmatn-*.ttf` (همهٔ وزن‌ها): فونت فارسی تیترها و متن
- `Orbitron-*.ttf`: فونت لاتین فضایی (NOVA و اعداد)
- `JetBrainsMono-*.ttf`: فونت کدها

اگر روی سیستم کلاس فونت‌ها نصب نیست و اجازهٔ نصب ندارید، از `Nova.pdf` استفاده کنید.

## نکات اجرا
- **PowerPoint 2019 یا 365** لازم است تا ترنزیشن Morph (حرکت نرم نورها و لوگو بین اسلایدها) کار کند. در نسخه‌های قدیمی‌تر به‌جایش Fade اجرا می‌شود.
- انیمیشن‌های هر اسلاید **خودکار** شروع می‌شوند؛ فقط برای رفتن به اسلاید بعد کلیک کنید.
- متن گفتار هر اسلاید در بخش **Notes** (یادداشت‌های سخنران) نوشته شده است. در حالت Presenter View فقط شما آن را می‌بینید.
- در اسلاید ۱، «نام شما» و «نام استاد» را عوض کنید.
